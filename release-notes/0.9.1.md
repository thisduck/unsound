## Updates inside unsound

- Automatic update checks on launch and every 12 hours, with an option to turn them off.
- An update button in the main window, an updates page in settings, and “Check for updates…” in the menu bar.
- Release notes, download progress, retryable errors, and a separate **Update & restart** button.
- Signed update archives verified before installation. Restart waits for recordings, processing, and unsaved meeting notes.

If you are using v0.9.0 or earlier, install this DMG manually once. Future releases can be installed from inside unsound.
